# Norvak Web · V3

**Independent web design and front-end development by José Cortés.**

Modern, functional websites that load fast and feel good.

Norvak Web is my independent web development brand, based in Winter Haven, Florida. I build websites for small businesses with a focus on clear information, visual identity, responsive layouts, and straightforward ways to get in touch.

This repository is the fresh foundation for the third version of my portfolio and services website.

## Project status

**Repository foundation — website implementation pending.**

The initial commit contains project documentation and development conventions. The new website source, screenshots, and deployment will be added as the rebuild progresses.

The [existing Norvak preview](https://norvak-web-v2.rareeel6.chatgpt.site) remains available as a design reference. It is hosted separately and is not deployed from this repository.

## What I’m building

- A clear introduction to Norvak and the services I offer.
- A portfolio of selected projects with honest descriptions of my work.
- Dedicated Home, Work, Services, About, and Contact pages.
- English and Spanish content with consistent navigation.
- A responsive interface with accessible interactions and restrained neon accents.
- A clear contact path, with submission behavior documented accurately.

These are the goals for the rebuild, rather than a list of features already shipped in this repository.

## Technical direction

The planned implementation uses **semantic HTML, CSS, and vanilla JavaScript**. The initial site will not require a framework or a build step. Development will use VS Code, Git, and a local preview server.

Any future dependency will be documented with its purpose and setup instructions.

## Get started

```bash
git clone https://github.com/Chepot87/Norvak-Web-V3.git
cd Norvak-Web-V3
code .
```

Review the project brief and roadmap first. Once `index.html` is added, open it with VS Code Live Server to preview the website locally. Deployment instructions will be added when a host is configured and verified.
